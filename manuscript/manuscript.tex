\begin{abstract}
This manuscript documents the segmentation benchmark implemented in the repository for vessel analysis in histological images with DAB immunostaining. Four approaches were compared under a unified binary-mask interface: a custom VeSpA image-processing pipeline (color-based), the Segment Anything Model (SAM) with automatic mask generation, a pretrained Ultralytics YOLOv8 segmentation model, and a hybrid VeSpA-SAM approach combining color priors with prompt-guided foundation-model refinement. Evaluation was performed on four histological TIFF images with paired binary vessel masks using Dice coefficient, intersection over union, precision, and recall. In the current repository benchmark, VeSpA achieved the highest mean Dice coefficient (0.7433), followed by the hybrid VeSpA-SAM pipeline (0.6979), SAM (0.2988), and YOLOv8-seg (0.1263). Mean runtime per image was 3.80 s for VeSpA, 148.00 s for the hybrid method, 100.49 s for SAM, and 4.36 s for YOLOv8-seg. This manuscript reports the implemented methods and the benchmark outcomes produced by the repository code.
\end{abstract}
